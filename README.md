# OBD Diagnostics Studio - HP Tuners Edition - Smooth 60fps

Professional OBDLink MX/MT tool for GMT400 1996 Sierra with HP Tuners VCM Scanner clone features.

## Features
- Real analog gauges with 60fps smooth interpolation (target + display lerp)
- Colorblind-safe palettes: Okabe-Ito gold standard, Deuteranopia/Protanopia/Tritanopia safe, High Contrast
- 15 gauges: RPM, MAP, MAF, TPS, ECT, IAT, Spark, STFT/LTFT B1/B2, O2, Knock, Speed
- Refresh rates: 16ms (60fps Max), 20ms (50Hz CAN Fast), 50ms (20Hz), 100ms, 200ms (VPW Safe)
- HP Tuners tabs: Gauges, Chart vs Time (300 points), Channels, DTCs/Readiness, Histograms, VCM Controls, PID Sniffer
- VCM Controls: Fuel Pump, Injector Kill 1-8, 4L60E Park/1st-4th/TCC, Crank Relearn, Idle Learn, Fans, A/C
- Web + Desktop versions

## Quick Start
1. Unzip
2. Double-click START_HERE.bat
3. Push to https://github.com/MisterMidgett/OBDLink-MX-and-MT
4. GitHub Actions auto-builds .exe

## Hardware
- OBDLink MX/MT
- 1996 Sierra 5.7L Vortec - J1850 VPW, Header 6C 10 F1, Mode 22 PIDs
